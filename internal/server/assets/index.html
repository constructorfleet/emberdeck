      New vector project

      Imports static paths, basic shapes, and text in the emberdeck-stick-v1 monoline font. Text accepts 1–32 ASCII letters, digits, spaces, and .,:;!?+-/_() at a unitless font size of 1–100 viewBox units; it becomes open strokes for engraving. Nested SVG groups compose transforms through 16 levels. SVG C/c/S/s and Q/q/T/t curves become lines within 0.05 mm chord deviation; circles and ellipses become 32-point paths. M/L/H/V/Z and cubic/quadratic path commands and element transforms are supported. Text styling, tspan, unsupported attributes, and machine settings are rejected.
