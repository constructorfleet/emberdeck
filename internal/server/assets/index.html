Machine profiles

New declared profile

Operator declaration only: set this maximum to the controller's $30, declare $31=0 and $32=1, and prepare the active lower-left work origin. Start refuses a generated job unless the driver's controller reports the same $30, $31, and $32 (read with the read-only $$ command); work coordinates are not verified. EmberDeck does not home, zero, or change controller settings. Commanded S percentage is not a measurement of optical output.
